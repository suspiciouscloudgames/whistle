# Whistle

[브라우저에서 열기](https://suspiciouscloudgames.github.io/whistle/)

## 개발 서버 실행

Node.js 22.13 이상이 필요합니다. 프로젝트 폴더에서 실행합니다.

```sh
npm ci       # 최초 설치
npm run dev
```

시작 시 Pd 패치가 자동으로 컴파일됩니다.

- 게임: http://127.0.0.1:5173/whistle/
- 오디오 테스트: http://127.0.0.1:5173/whistle/audio-lab/index.html

포트가 사용 중이면 터미널에 표시되는 주소를 이용합니다. 종료는 `Ctrl+C`입니다.

## 멀티플레이 실험

**함께 만들기 → 방 링크 복사**로 같은 서버의 세계를 함께 편집할 수 있습니다.
현재 칸은 사용자 색으로 표시되며, 3D에서는 모습 대신 위치에 따른 시험음이 들립니다.
활성 3D 인원 1~4명에 따라 개인의 소리가 단음·화음·리듬 화음으로 바뀝니다.
[별도 사운드 패치](audio/multiplayer-interaction.md)에서 이 디자인을 수정할 수 있습니다.
한 PC에서 두 창으로 소리를 테스트하려면 두 창 모두 **로컬 테스트: 백그라운드 소리 유지**를 켠 뒤 플레이를 누릅니다.
방은 서버 메모리에 저장하므로 결과는 파일로 내보내 보관하세요.

빌드한 앱과 방 서버는 `npm run build && npm start`로 실행합니다.
정적 GitHub Pages 배포에는 방 서버가 없으므로 별도 서버가 필요합니다.
[최소 규칙·실행 방법·제약](docs/multiplayer.md)을 참고하세요.
