# Whistle

[브라우저에서 열기](https://suspiciouscloudgames.github.io/whistle/)

## 개발 서버 실행

Node.js 22.13 이상이 필요합니다. 프로젝트 폴더에서 실행합니다.

```sh
npm ci       # 최초 설치
npm run dev
```

시작 시 Pd 패치가 자동으로 컴파일됩니다.

- 게임: http://127.0.0.1:5173/whistle/
- 오디오 테스트: http://127.0.0.1:5173/whistle/audio-lab/index.html
- UWB 위치 테스트: http://127.0.0.1:5173/whistle/uwb-lab/index.html

포트가 사용 중이면 터미널에 표시되는 주소를 이용합니다. 종료는 `Ctrl+C`입니다.

## UWB 위치 최소 테스트

상단 메뉴는 `샘플 세계`와 `Whistle 3D` 두 가지입니다.
`Whistle 3D`는 새 창을 열지 않고 같은 브라우저·서버 주소에 저장된 세계를 표시합니다.
별도로 게임 편집기(`/whistle/`)를 열면 편집 중인 세계를 자동으로 받아옵니다.
저장된 세계가 없으면 편집기를 열 때까지 기다리며, 불러오기 실패 시 오디오를 켜지 않습니다.

지면·아이콘·높이·구멍 수정, 실행 취소/다시 실행, 세계 가져오기가 실시간 반영됩니다.
관객의 미터 좌표·보드 높이·공간 보정값은 유지됩니다.
연결은 같은 브라우저·서버 주소의 `BroadcastChannel`로 전달되며, 별도 URL 파라미터가 필요하지 않습니다.
여러 편집기가 열려 있으면 마지막으로 세계 변경을 전달한 편집기를 따릅니다.
자동 저장이 실패해도 메모리의 편집 문서를 받아오며, 테스트 페이지는 세계를 수정하거나 저장하지 않습니다.

오디오 시작·종료 버튼은 전시장 매핑 위에 있습니다.
Whistle 3D 모드에서는 편집기로 이동해도 오디오를 유지합니다.
연결된 편집기의 종료·연결 끊김·잘못된 세계에서는 음소거하고, 정상 문서가 다시 연결되면 재개합니다.
`오디오 종료`는 자동으로 재개하지 않습니다.
`샘플 세계`를 누르면 실시간 연결과 오디오를 종료하고 샘플로 돌아갑니다.

장비 없이 좌표 입력이나 평면도 클릭·드래그로 관객 1명의 위치를 시험합니다.
왼쪽·중앙·오른쪽 위치 버튼으로 샘플 세계의 풀·바위·물 구역을 비교하고,
`오디오 시작`을 누르면 기존 Pd 시험음으로 반응을 확인할 수 있습니다.
물은 현재 패치에서 수신값만 확인합니다.

저장된 세계와 세계 JSON 파일은 Whistle 편집기에서 불러옵니다.
UWB 테스트 페이지에는 별도의 저장본 읽기·파일 가져오기 메뉴가 없으며, 기존 세계를 수정하거나 자동 저장하지 않습니다.

가로·세로는 미터 단위이며, 원점과 회전을 설정할 수 있습니다.
현실 좌표는 원점 기준으로 역회전한 뒤 가로·세로에 각각 맞춰 전체 격자에 대응합니다.
회전 0°에서 +X는 평면도 오른쪽, +Z는 아래쪽입니다.
좌표 JSON은 `{"x":1,"z":3,"boardHeight":1.5}`처럼 **위치 계산이 끝난 미터 좌표**를 입력합니다.
`보드 높이 (m)`로 현실 바닥 기준 높이를 가상 입력합니다. 시험 범위는 0~10m이며 기본값은 0입니다.
JSON에서 `boardHeight`를 생략하면 현재 높이를 유지합니다. 평면 이동이나 세계 편집도 보드 높이를 바꾸지 않습니다.
별도 Pd 버스 `whistle-board-height`로 전달하며, 시험음은 높이 1m마다 110Hz 올라갑니다.
0m에서는 기존 시험음과 같고 음량은 유지합니다. 잘못된 높이는 오디오를 음소거합니다.
`lib/uwb-position.ts`의 `sampleTrackedPosition`이 이후 센서 어댑터에서 재사용할 입력 경로입니다.

3D 표식과 기존 플레이어 파라미터 `y`는 가상 지면 높이를 사용하고 방향은 0으로 고정합니다.
보드 높이는 표식·플레이어 이동·지형 판정에 영향을 주지 않습니다. 점프·낙하·이동 속도를 추정하지 않습니다.
범위 밖·바닥 없음·잘못된 좌표에서는 오디오와 3D 표식을 중지합니다.
독립 테스트에서는 창 포커스를 잃거나 페이지를 숨기면 오디오를 종료하며, 다시 시작 버튼으로 켭니다.
단발 좌표를 유지하는 수동 테스트이므로 수신 시간 초과 판정은 하지 않습니다.

이번 범위는 편집 문서 실시간 연결 → 좌표 변환 → 기존 환경 판정 → 3D 표식 → WebPd입니다.
실제 DW3000 연결, 앵커 거리로부터 위치 계산, 추적 필터, 4명 동시 처리,
규칙 이벤트 및 ESP32 무선 오디오 출력은 아직 포함하지 않습니다.

```sh
npm run test:uwb  # 좌표 변환·브라우저 연결 테스트
npm test          # 기존 테스트 포함 전체 회귀 테스트
npm run build
```
