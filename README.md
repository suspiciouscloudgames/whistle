# Whistle

[브라우저에서 열기](https://suspiciouscloudgames.github.io/whistle/)

사진과 그림을 기호에 연결하고, 타일을 배치해 작은 세계를 만드는 브라우저 창작 도구입니다. **만들기**에서 배치하고 **플레이**에서 탐험합니다. 스마트폰 터치패드와 PC의 WASD를 지원합니다.

사진·그림과 작성 중인 세계는 각자의 브라우저에 저장됩니다. **공유**에서 세계 링크를 만들거나 파일로 내보낼 수 있습니다. 다른 도메인에서 작성한 세계는 파일로 내보낸 뒤 **불러오기**로 가져오세요. 기존 Sites 버전의 저장 공간과 별개입니다.

## 개발

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

React와 Three.js로 실행되는 정적 웹앱입니다. 외부 AI 서비스나 서버 저장소를 사용하지 않습니다. `main`은 소스 저장소이며, 빌드 결과인 `dist`를 `gh-pages` 브랜치에 올리면 GitHub Pages에 배포됩니다.

이 배포는 Whistle 원본 커밋 `1f207a0ec18d2bbb3a58513b9365176c8ca6822c`의 기능을 옮겼습니다. Pages의 `/whistle/` 경로에 맞춰 정적 빌드를 구성했으며, 원본의 서버 인증 및 호스팅 설정은 포함하지 않습니다.
